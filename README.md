# Automated Customer Support Agent (n8n + Google Gemini)

## Description
This project implements an AI-powered customer support agent using the n8n automation platform
and Google Gemini. The agent automatically handles customer queries, maintains conversation
context, and provides intelligent responses without human intervention.

## Features
- Automated customer query handling
- AI-powered responses using Google Gemini
- Conversation memory for multi-turn chats
- Reduced manual support effort
- End-to-end workflow automation

## Technologies Used
- n8n
- Google Gemini
- AI Agent
- Simple Memory
- JavaScript

## Workflow Overview
1. Customer sends a query
2. Query is passed to AI agent
3. AI processes message with conversation memory
4. Response is generated and sent automatically

- Designing conversational AI agents
- Managing context using memory
- Building real-world support automation
- AI integration using low-code tools
